# CO2 Sniffer

CO2 Sniffer 是配合 Flipper Zero 使用的 BMP388 + SCD30 环境监测扩展板。将扩展板
插入 GPIO 排针并启动应用后，即可查看 CO2、温度、湿度、气压和估算海拔；测量
结果还可保存到 microSD 卡，或通过 USB 发送到电脑。
其中 `SW/` 软件工程由 OpenAI Codex 编写。

![安装在 Flipper Zero 上运行的 CO2 Sniffer](docs/co2-sniffer-installed.jpg)

## 主要功能

- 同时测量 CO2、温度、湿度和气压，并根据气压估算海拔。
- 提供多种实时仪表布局，以及 5 项测量数据的历史曲线和时间尺度。
- 可按指定间隔和时长将测量结果保存为 CSV，也可通过 USB 发送到电脑。
- 某个传感器暂时不可用时，另一个传感器仍可继续工作；恢复连接由应用自动完成。

为避免刚启动时的不稳定读数影响趋势，历史曲线不会记录应用启动或 SCD30 重新
连接后的前 10 秒数据。

## 按键操作

按键功能会随当前画面变化。表中未注明“长按”的操作均为短按。

| 当前画面 | 按键 | 功能 |
| -------- | ---- | ---- |
| 仪表页 | **左** | 打开 **Data Recording** 记录页 |
| 仪表页 | **右** | 打开第一项历史曲线 |
| 历史曲线页 | **左 / 右** | 查看上一项 / 下一项曲线；到达首尾时返回仪表页 |
| 仪表页 | **上 / 下** | 切换仪表布局 |
| 历史曲线页 | **上 / 下** | 切换曲线时间尺度 |
| 仪表页 / 历史曲线页 | **BACK** | 打开清空历史确认；按 **OK** 清空，按 **BACK** 取消 |
| 记录页 | **上 / 下** | 选择采样间隔、记录时长或 **Start** |
| 记录页 | **OK** | 更改所选设置；选中 **Start** 时开始记录，记录期间按下则停止 |
| 更改记录设置时 | **左 / 右** | 选择所需数值 |
| 更改记录设置时 / 记录页 | **BACK** | 结束当前修改；未修改设置时返回仪表页 |
| SCD30 设置页 | **上 / 下**、**OK** | 选择设置并更改开关状态，或进入手动校准 |
| 手动校准输入页 | **左 / 右**、**上 / 下** | 选择并调整数位；按 **OK** 核对校准值 |

以下功能需要按住按键：

| 使用位置 | 操作 | 功能 |
| -------- | ---- | ---- |
| 记录页，且未在更改设置 | 按住 **左** 2 秒 | 打开 SCD30 设置页 |
| 核对手动校准值时 | 按住 **OK** 2 秒 | 进度条完成后开始校准 |
| 未显示校准或退出确认时 | 长按 **OK** | 开启或关闭背光常亮 |
| 任意页面 | 长按 **BACK** | 打开退出确认；按 **OK** 退出，按 **BACK** 取消 |

## 数据记录

数据记录适合观察一段时间内的环境变化。在仪表页按 **左** 打开 **Data
Recording**，选择采样间隔和记录时长，然后选择 **Start**。记录会在达到设定
时长后自动结束；选择“持续记录”时，或需要提前停止时，按 **OK** 结束记录。

| 设置 | 可选值 |
| ---- | ------ |
| 采样间隔 | 2 秒、5 秒、10 秒、30 秒、1 分钟 |
| 记录时长 | 1 分钟、5 分钟、10 分钟、30 分钟、1 小时、2 小时、8 小时、24 小时、持续记录 |

记录文件保存在 microSD 卡的 `/ext/co2_sniffer/` 目录，文件名中包含开始时间、
采样间隔和记录时长。每条记录包括时间、已记录时长以及当时的各项传感器读数；
传感器暂时不可用时，相应位置会留空。屏幕上的 `REC` 闪烁表示正在记录，出现
`SD!` 则表示文件无法写入，请检查 microSD 卡。

## SCD30 设置与校准

在 **Data Recording** 记录页按住 **左** 2 秒，即可打开 **SCD30
Calibration**。这里提供两项日常设置：

- **Pressure comp**：根据 BMP388 测得的当前气压，提高 SCD30 的测量准确度。
- **Auto calib (ASC)**：让 SCD30 在长期使用中自动调整基准。

首次使用时，气压补偿默认开启，ASC 默认关闭。应用会记住此后的更改，并在下次
启动时继续使用。

### 手动校准

只有在读数出现明显偏差，并且手边有可靠的 CO2 参考浓度时，才建议进行手动
校准。不要直接把室外空气当作 400 ppm 标准。

校准前，让传感器在浓度稳定的参考环境中运行至少 2 分钟，并让人员面部远离
传感器。选择 **Manual calibration** 后输入实际参考浓度（`0400–2000 ppm`），
按 **OK** 核对数值，再按住 **OK** 2 秒。进度条走完后，传感器会使用该参考值
进行校准。

## 硬件

扩展板通过 2.54 mm 1×10 排针连接到 Flipper 的 GPIO 口，板载传感器如下：

| 器件 | 功能 | I2C 地址 |
| ---- | ---- | -------- |
| Sensirion SCD30 | CO2、温度、湿度 | 0x61 |
| Bosch BMP388 | 温度、气压 | 0x76 |

I2C 使用 GPIO C0（SCL）/ C1（SDA），扩展板由 Flipper 的 3V3/5V 引脚供电。
KiCad 原理图和 PCB 设计源文件位于 `HW/`。

## 异常处理

如果某个传感器暂时断开，其对应读数会显示为不可用，另一个传感器仍可继续
测量。应用会自动尝试恢复连接；如果屏幕提示 I2C 总线无法恢复，请按提示退出
应用并重新启动 Flipper。

- `PROTOCOL-zh.md` — USB CDC 串口协议完整文档。

## USB 数据输出

需要在电脑上接收实时读数时，请通过 USB 连接 Flipper，并选择系统识别出的第二个
虚拟串口；第一个串口供 Flipper CLI 使用。测量数据采用二进制帧格式，完整格式和
解析方法见
**[PROTOCOL-zh.md](PROTOCOL-zh.md)**。
